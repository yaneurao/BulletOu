## 転送用固定メモリの上書き

SFNNとNNUEの2-slot非同期転送で、GPUストリーム上のwaitはdevice bufferを保護するが、CPUがpinned staging bufferを上書きするのを止めない。前回のH2D転送が未完了のままslotを再利用すると、前のbatchの教師値や入力が次のbatchの値に置き換わりうる。

転送を意図的に遅らせたSFNNテストでは、修正前に最初の教師値 `[0.1, 0.2, 0.3, 0.4]` が `[0.9, 0.8, 0.7, 0.6]` に置き換わることを再現した。修正はCPUが同じpinned slotを書き直す前に、そのslotの前回のupload完了eventを待つ。修正後はSFNN・NNUE両方の回帰テストが通過した。

これは転送処理のバグであり、教師データファイルの問題ではない。既存の学習で実際に何回発生したか、loss上昇の原因であるかは未確認。修正前の速度・精度比較には、このバグの影響が混じっていた可能性がある。

## L1 QATの畳み込みと整数詰めの融合

対象shapeでL1のfactorizer畳み込み時に整数形式への詰めも行い、後続の再読み込みと詰め直しを省く。従来処理は環境変数 `BULLETOU_FUSED_L1_PACK_REFERENCE=1` で選択できる。shape・QAT・GPU条件が合わない場合は従来処理を使う。

幅2304のGPUテストで、通常値・量子化上限・下限を含むFP32出力と整数詰め結果が従来方式と一致。実checkpointの診断では、融合が有効だった1,219 stepすべてで各stepの32,514,048整数語を従来方式と照合し、一致した。

転送修正後の1,220 step比較:

| 条件 | 従来時間 | 融合時間 | 従来 qacc / qloss | 融合 qacc / qloss |
|---|---:|---:|---|---|
| FT FP32 | 94.762秒 | 93.792秒 | 58.07482% / 0.72338873 | 58.07734% / 0.72338921 |
| all_optim=true | 78.496秒 | 77.709秒 | 58.07814% / 0.72320086 | 58.08318% / 0.72321594 |

融合による短縮は両条件で約1%。GPU逐次計測のstep 5〜10平均では、forwardがFP32で19.151→18.486 ms、all_optimで13.011→12.357 msだった。計測時の転送時間・GPU状態にはばらつきがある。全体のGPU逐次時間はFP32では65.612→65.003 ms、all_optimでは52.358→52.514 msで、後者の6 step平均では全体改善を確認できなかった。

## all_optimの切り替え

sb 324のcheckpointを読み込み、epochごとに `false → true → false` として各8 batch実行。ログで4つのFT FP16設定の切り替えと各epochの検証を確認した。24 stepではFP16範囲超過の警告は出なかった。またSGDのFT momentumについて切り替えとcheckpoint roundtripのGPUテストが通過した。長期間の学習品質を保証するものではない。

転送修正後の2 sb相当では、重み・一時勾配・activationをFP16、momentumをFP32にした条件は79.174秒、全FP16は77.709秒、全FP32は93.792秒。前者のqacc/qlossは58.08238% / 0.72317296、全FP16は58.08318% / 0.72321594。今回の2 sb相当では両条件ともclip警告なし。修正前には全FP16でclip警告が出た実行もあり、長時間で範囲超過が起きないとは言えない。

## 採用しなかった候補

FP32 SGD更新を4要素ずつ処理する候補と、FP32 FT逆伝播を2要素ずつ処理する候補は、元の演算と一致するテストを通過したが、安定stepのGPU計測では短縮できなかったため採用しなかった。

## 2026-11-19: L1 factorizer reads tiled

For the 2304-wide, 16-output, 3528-bucket shape, the folded L1 QAT
weights now use a 32-input by 8-output tile. Factorizer reads are coalesced,
while residual reads and writes remain contiguous. Shared-memory padding
avoids bank conflicts. The accumulation order and integer packing are retained.
`BULLETOU_L1_TILED_FOLD_REFERENCE=1` selects the previous kernel for comparison.

The production-width GPU test compares all folded float bits and all packed
words with the existing implementations, including clipping. It passed.
The ordinary CUDA library test suite passed (82 passed, 99 ignored).
Checkpoint-based 1220-step runs, same sb 324 checkpoint and settings as above:

| FT optimizer storage | previous seconds | tiled seconds | previous qacc / qloss | tiled qacc / qloss |
| --- | ---: | ---: | --- | --- |
| FP32 | 93.792 | 92.109 | 58.07734% / 0.72338921 | 58.07333% / 0.72336513 |
| all_optim | 77.709 | 75.541 | 58.08318% / 0.72321594 | 58.08238% / 0.72319025 |

Training times only; GPU profiles show steady forward times of about 18.49 to

The runs are short and do not establish long-term learning behavior.
