参考: 本学習のepoch 3 sb 325〜378の54個のsb終了時qaccは、平均59.60094%、標本標準偏差0.04830ポイント、最小59.4904%、最大59.7191%。同じ54点のqlossは平均0.72658107、標本標準偏差0.00065960、最小0.72542942、最大0.72793704。これは時間変化を含むばらつきで、独立した反復実験の誤差分布ではない。

## L1整数QAT backward

連続STEの判定で、整数L1出力から畳み込み後のmaster biasの量子化端数を復元する。linearの0と1、二乗分岐の正負飽和境界と0付近の判定、二乗分岐の勾配の大きさに反映する。forwardの量子化・整数演算は変更していない。L1以外の通常経路は対象外。

修正前にbias `0.25/8128` でL1のlinear勾配が0になるGPU再現テストの失敗を確認した。修正後、正負・上下境界、二乗分岐、pairを含む畳み込みbias、境界以外の二乗勾配の数値照合に成功。整数QAT関連GPUテスト13件、SGD関連GPUテスト14件、CUDAライブラリ通常テスト82件に成功。今回追加したL1端数の影響が実checkpointの停滞を引き起こしたとは証明していない。

## 16 sb相当の独立実験

同じcheckpoint・データ位置から9,760更新、639,631,360局面。検証は最後に1回、全921,060局面。8 sb比較と同じ最終バイナリを使用。

FT QAT有効のqaccは8 sbの59.79888%から16 sbで59.55806%になり、上昇は継続しなかった。qlossは8 sbの0.72551137から0.72486168に低下した。8 sbと16 sbは同じ出発点からの独立した実行で、連続した1回の学習での中間点ではない。16 sb同士ではqaccはほぼ同じ、qlossはFT QAT有効のほうが0.00306618低かった。

QAT無効16 sbでは `BULLETOU_SGD_TRACE_LAYERS=1` を有効にし、開始・終了時点の重みを比較した。L2重み6,773,760個のうちFP32値が変わったものは4,096,403個、scale 64で丸めた値が変わったものは146個、FP32絶対変化の全要素平均は3.67e-7。L3重み225,792個ではそれぞれ180,534個、27個、2.30e-6。L2 biasは225,792個中10,692個、L3 biasは3,528個中1,090個のscale 8128の丸め値が変わった。二時点間に変化して戻ったものは数えない。未使用・低頻度bucketを含む全要素の統計であり、勾配の流れがないという意味でも、これだけがqacc停滞の原因という意味でもない。

## 勝敗との混合

FT FP32・FT QAT有効、その他は同じ設定で `lambda=0.5` にした。これは教師評価と勝敗を半々に混ぜるため、`lambda=1` のqlossとは直接比較できない。開始から1更新後のqacc/qlossは59.62408% / 0.73236150、同じ条件で4,880更新後は57.93819% / 0.68190378。独立した実行のため連続runの中間値ではない。混合条件内ではqlossが下がったが、qaccは低下した。8 sbの`lambda=1`条件のqacc 59.79888%にも届かず、今回の短期比較では採用しない。

## L2重みの学習率のみ100倍

FT FP32・FT QAT有効、lambda=1。`sfnn_l2_lr_mult=100`、`sfnn_l2_bias_lr_mult=0.01` によりL2 biasの実効倍率は1に保つ。他は8 sb基準と同じ。4,880更新後のacc/qacc/loss/qlossは59.63359% / 59.77744% / 0.72710693 / 0.72454399。基準の59.63715% / 59.79888% / 0.72707820 / 0.72551137に対し、qaccは0.02144ポイント低く、qlossは0.00096738低い。

全6,773,760個のL2重みのうち開始・終了時にFP32値が違うものは5,455,922個、scale 64の丸め値が違うものは7,503個。2時点間に戻ったものは数えない。L2の検証上限飽和率は全体で表示上0.0000%、unit最大0.2437%（bucket 6、unit 27、3/1,231局面）。FTのunit上限最大は62.5704%（unit 372、1,152,621/1,842,120視点）。上限飽和のみで、下限飽和の分布は未測定。

同条件9,760更新後のacc/qacc/loss/qlossは59.57766% / 59.67004% / 0.72688353 / 0.72467154。16 sb FT QAT基準の59.57330% / 59.55806% / 0.72676563 / 0.72486168と比べ、qaccは0.11198ポイント高く、qlossは0.00019014低い。ただし倍率100のqacc自体は8 sb時点59.77744%から低下しており、1回の比較だけで安定改善や推奨値とは判定しない。

16 sbで量子化値が開始時と異なるL2重みは13,573/6,773,760個、FP32値が異なるものは5,574,343個。L2上限飽和率は全体で表示上0.0000%、unit最大0.3249%（bucket 6、unit 27、4/1,231局面）。FT unit上限最大は65.3883%（unit 372、1,204,531/1,842,120視点）。上限以外は未測定。通常倍率FT QAT有効の16 sbでは重み変化のtraceを取得していないので、上記のQAT無効16 sb traceとの量子化値変化数の差を倍率だけの影響とは断定できない。
